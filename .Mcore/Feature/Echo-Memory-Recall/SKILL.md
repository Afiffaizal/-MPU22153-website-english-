# Echo Memory Recall

After `Login`, run `Recall -Query <specific words or question>` to search the active user's local memory and, in Team mode, unlocked shared project events. Inspect returned source labels and dates. A keyword hit is a lead to verify, not proof of the current state. If a record conflicts with code or the latest user instruction, resolve the conflict from current evidence.

See `recall-format.md` for the result format. Never read another user's ignored local cache directly.
