# Audit MemoryCore instructions

Inspired by [lobotomized-claude-code](https://github.com/skrabe/lobotomized-claude-code); performed directly by the active AI on project-owned instructions.

Inventory the rules read at startup, locate duplicates, identify contradictory priorities and check that referenced commands/files exist. Consolidate repeated requirements into one canonical rule with short pointers. Keep identity, login, memory/diary, user scope and truthful reporting intact.

For a proposed change, show which behavior should improve and verify representative requests before replacing the rule. Keep task-specific guidance in a relevant skill so unrelated tasks do not load it. Do not patch vendor binaries or internal system prompts.
