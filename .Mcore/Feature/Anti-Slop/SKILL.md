# Quality review

Native workflow informed by [anti-slop](https://github.com/miqdadbadjuber/anti-slop).

1. Read the user's actual brief and existing design direction. Determine whether the output is prose, UI or code.
2. Check factual claims and remove invented statistics, testimonials, citations or capabilities.
3. For prose, replace filler, repetition and abstract claims with concrete information. Preserve tone, language and necessary detail.
4. For UI, inspect information hierarchy, content fit, interaction states and accessibility. Remove decorative elements that obstruct the task; do not impose a default palette or redesign without scope.
5. For code, inspect unnecessary abstractions, duplicated logic, missing error handling and misleading comments.
6. Fix issues in scope and give a short evidence-based result. Load UI UX Pro Max for usability or Hallmark for visual direction only when needed.
