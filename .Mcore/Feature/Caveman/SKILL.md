# Concise output

Native skill informed by [Caveman](https://github.com/juliusbrussee/caveman). Apply on every task while preserving the user's language and requested depth.

Lead with the result. Use short, complete sentences and omit repeated context. Preserve numbers, names, paths, qualifications and evidence needed to act. Do not shorten code, schemas or commands by changing their meaning.

For large tool output, select the relevant data before loading it. Use Context-Mode or RTK where appropriate; keep a way to inspect raw evidence. Never claim exact token savings from shorter prose alone.

This is the bundled communication and context discipline. It requires no Caveman proxy, network interception, account or provider configuration.
