# Minimum sufficient work

Native skill informed by [Ponytail](https://github.com/dietrichgebert/ponytail). Apply on every task, including research, writing and planning.

Before creating anything, consider in order: already solved in the project; available native capability; small composition of existing parts; a new implementation. Choose the first option that completely meets the user's intent.

Keep required validation, accessibility, error handling and meaningful verification. Reduce work by removing redundant steps or abstractions, not by dropping requirements. For non-code tasks, use the shortest complete explanation or artifact that supports the decision.

At review, identify anything added that the task does not need. Measure performance or token improvements when claimed. This bundled instruction runs in the active AI; no provider plugin or new account is required.
