# Memory consolidation

Use only for an actual migration. Read `migration-guide.md`, preserve a backup, complete setup and authenticated Login, then import verified records through `SaveMemory`, `SaveDiary`, or `SaveTopic` under the correct author. Confirm sample results through `Recall`. Resolve uncertain ownership before importing and keep the original backup until the owner has reviewed the outcome.

New MemoryCore projects already use `.Mcore` and need no migration. Do not invent old memories to populate a blank template.
