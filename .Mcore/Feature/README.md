# Shared feature catalog

Each folder contains a complete MemoryCore instruction workflow. Login catalogs it, Route suggests relevant skills, and the active AI loads the required SKILL.md. These are independently written MemoryCore workflows credited to the linked sources in each skill. They are not complete ports of the upstream products.

| Work | Features |
| --- | --- |
| Memory and diary | Save-Diary-System, Echo-Memory-Recall, Topic-Diary-System, Memory-Compaction-System, Memory-Consolidation-System, AI-Memory-Handoff |
| Planning and teamwork | Work-Flow, BMad-Method, AutoGPT-Patterns, Agency-Roles, TeamAI-Practices |
| Economy on every instruction | Ponytail, Caveman, RTK; Context-Mode for large reads |
| Safety and improvement | Strix-Security, Self-Improvement-Research, Prompt-Audit |
| Visual and content work | Archify-Diagrams, Anti-Slop, Hallmark-Design, UI-UX-Pro-Max, Vox-Director |
| Skill/prompt creation | Skill-Recommender, Book-To-Skill, Prompt-Master |

Strix-Security runs directly through the active AI without a separate login or model API. RTK and SkillSpector are provisioned by device setup. Other workflows use tools already available to the host. Diagrams/text/code can be authored by the AI; rendered media and background schedules require actual host capabilities. Never report a deliverable that was not produced.

See [skills and MCP operations](../skills-and-mcp.md) for selection, scope, installation and provider limits.
