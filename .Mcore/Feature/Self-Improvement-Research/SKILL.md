# Test improvements

Informed by [Awesome Self-Improving Agents](https://github.com/selfimproving-agent/awesome-Self-Improving-Agents). The active AI evaluates changes to prompts, memory, tools and workflows.

State the observed failure and collect a reproducible example. Propose one change and define a comparison against current behavior: task success, accuracy, context size, time or cost as applicable. Include a case that should stay correct.

Test on an isolated copy, inspect failures, and keep changes only when evidence supports them. Record limitations and the rollback procedure. Save validated lessons through MemoryCore, and promote them to shared rules only within the user's authorized scope.

This is an evaluation procedure, not autonomous model training or permission to change its own goals.
