# Document to reusable skill

Native workflow informed by [book-to-skill](https://github.com/virgiliojr94/book-to-skill).

1. Read the provided document with the active host's file/PDF tools. Identify title, edition, chapters and page/section references; flag unreadable pages.
2. Ask Team or Personal if scope was not supplied. Establish that source material may be used and shared under the chosen scope.
3. Extract decision rules, procedures, exceptions and worked examples into concise supporting reference files. Preserve source references; do not invent missing content.
4. Write a SKILL.md with a precise trigger, a short operating procedure and links to relevant references. Load references on demand.
5. Review a sample question against the original document and correct omissions. Scan the completed candidate using Skill Recommender before installation.
6. Explain which material was transformed and where it is installed. Record the addition; do not publish source documents automatically.

No separate converter account is required. If the current host cannot read the supplied format, report that capability gap rather than fabricating extracted text.
