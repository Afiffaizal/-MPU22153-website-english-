# Explainer video workflow

Native workflow informed by [Vox Director](https://github.com/Alisa0808/vox-director). Use the current AI's available media tools and local assets; do not require an Atlas Cloud key.

1. Establish topic, audience, duration, output format and supplied assets.
2. Write a beat map with narration, visual, duration and source evidence per beat. Resolve creative choices that materially affect production.
3. Produce a storyboard and style sample. Generate assets through tools already connected to the active host, or use permitted supplied assets.
4. Assemble visuals, narration, captions and music with an available video tool or ffmpeg. Verify timing, audio levels, captions, rights and file playback.
5. Deliver the actual output path and state which checks were performed.

If this host has no media generation or rendering tools, deliver the script/storyboard and report rendering as unavailable. Do not silently purchase a service or claim a video exists. A text-only AI cannot generate an MP4 merely by loading a skill.
