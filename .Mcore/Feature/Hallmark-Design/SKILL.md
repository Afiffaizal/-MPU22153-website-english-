# Deliberate interface design

Native workflow informed by [Hallmark](https://github.com/nutlope/hallmark).

Choose the user's operation: create, audit, redesign or study. For study, extract layout principles from the supplied reference without claiming its source code. For audit, report specific findings before changing code. For redesign, preserve the content, brand and information architecture the user requested.

Translate the brief into one visual direction: hierarchy, grid, spacing, typography, color roles and motion purpose. Implement it with the project's components and real content. Check small/large layouts, loading/empty/error states, keyboard use and contrast. Use the host's preview tools to verify rendering when available.

Do not add an upstream installer. A native design workflow does not reproduce the upstream theme dataset or guarantee visual quality without inspecting the output.
