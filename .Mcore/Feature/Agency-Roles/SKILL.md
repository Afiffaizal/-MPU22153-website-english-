# Specialist perspectives

Native workflow inspired by [agency-agents](https://github.com/msitarzewski/agency-agents). Choose a perspective based on the missing expertise, while retaining the registered AI identity.

| Need | Perspective | Deliverable |
| --- | --- | --- |
| Unclear value or scope | Product analyst | User outcome, constraints, acceptance checks |
| System boundaries | Architect | Interfaces, data ownership, tradeoffs |
| Usability or layout | Designer | Task flow, states, accessible layout |
| Implementation | Engineer | Working change and meaningful verification |
| Defect or regression | Reviewer | Reproduction, root cause, fix evidence |
| Research | Researcher | Primary sources, supported conclusion, uncertainty |
| Communication | Editor | Accurate text for the intended audience |

Use one or a few perspectives that resolve the actual task. Separate facts from assumptions and hand each output to the next step. Do not claim multiple independent reviewers when one AI performed all perspectives. Load related Feature skills on demand; no roster app or extra AI account is required.
