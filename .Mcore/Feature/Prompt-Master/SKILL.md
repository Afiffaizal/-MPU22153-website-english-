# Draft a useful prompt

Native workflow informed by [prompt-master](https://github.com/nidhinjs/prompt-master).

Identify the target tool, intended task, supplied input, expected output, constraints, audience and acceptance check. Use known project context without repeating the entire history. Ask only for a missing detail that materially changes the output.

Build the prompt around the task and acceptance check. Include examples or structured fields only when they remove ambiguity. Verify current model parameters against official documentation if the prompt depends on them. Check for contradictory requirements and trim redundant text.

Deliver a copyable prompt plus any essential assumption. Do not transfer private MemoryCore notes to another service without authorization; do not claim that wording guarantees zero retries or token waste.
