# Usability and design system

Native workflow informed by [UI UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill).

Identify the user's primary task, audience, platform, content and existing components. Map the task flow and states before choosing visual treatment. Reuse established design tokens; otherwise define spacing, typography, color roles, focus states and responsive breakpoints consistently.

Review keyboard navigation, labels, error recovery, touch targets, readable contrast and reduced-motion behavior. Check realistic long/empty content and loading/failure cases. Implement with the project's stack and test the important interactions.

Use Hallmark for visual direction and Anti-Slop for factual/copy checks when relevant. The active AI performs this procedure; no external design generator or dataset is required.
