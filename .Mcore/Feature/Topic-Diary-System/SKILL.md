# Save topic

1. Run `Login` and confirm the selected agent.
2. Choose a stable topic ID and write a note with context, verified discovery, and unresolved questions.
3. Run `SaveTopic -TopicId <id> -Text "<note>"`.
4. Also use `SaveDiary` if the day's event itself should be recorded.

Never write into another user's scope.
