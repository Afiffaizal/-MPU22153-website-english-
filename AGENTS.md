# MemoryCore entry for AI agents

The canonical rules and all project memory are in `.Mcore/`. Before doing any task, read [`.Mcore/rules.md`](.Mcore/rules.md), run `.Mcore/tools/Setup-MemoryCore.ps1 -Action Status`, and follow setup or `Login` as directed there. Use the registered AI agent name and call `RecordTurn` after every user instruction. Do not create provider-specific folders in this project for MemoryCore.
