System Overview

Proposed Architecture

The digital equipment loan system replaces physical record books with a verifiable, multi-tiered digital architecture.

Key Pillars
  • Frontend PWA Web Portal
  • Verification Cryptographic QR
  • Evidence Condition Photos
  • Notifications Automated Reminders
Select a component

Click on any component button below to inspect its technical role.

Core Engine

QR Code Engine

Generates secure, temporary QR tokens upon supervisor approval to verify collection and return.

Technical Responsibilities
  • Format Encrypted Payload
  • Validity Scheduled Loan Window
  • Scan Mechanism Single-use Handshake
  • Prevention Anti-Screenshot Token
Evidence & Audit

Photo Audit Service

Solves the problem of unrecorded damage and disputes between borrowers and resource officers.

Technical Responsibilities
  • Before Loan Mandatory capture at handover
  • After Return Comparison scan by officer
  • Compression WebP / Client-side downsample
  • Metadata ISO timestamp + Officer ID
Business Logic

Loan Manager

Orchestrates loan lifecycle states: Requested → Approved → Active / On Loan → Returned → Cleared.

Key Rules
  • Conflict Check Zero double-booking
  • Approval Gate Lecturer sign-off required
  • Overdue Tracker Auto-flag late items
Persistence

Data & Storage Tier

Dual storage architecture: Relational SQL for atomic transactions; Object Store for visual photo evidence.

Entities
  • Equipment Serial, Status, Model
  • Transactions Borrower, Supervisor, Dates
  • Photos Bucket Audit images indexed by LoanID
